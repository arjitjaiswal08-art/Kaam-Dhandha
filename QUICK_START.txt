                    GRAMCONNECT - QUICK START GUIDE

🚀 GET STARTED IN 3 STEPS:

1. Navigate to project:
   cd gramconnect

2. Run the application:
   ./run.sh
   
   OR manually:
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   python app.py

3. Open browser:
   http://localhost:5000

📋 TESTING WORKFLOW:

1. LOGIN AS ADMIN
   - Use credentials above
   - Explore dashboard
   - View statistics

2. REGISTER AS EMPLOYER
   - Click "Register as Employer"
   - Fill business details
   - Login as admin to approve

3. POST A JOB (as Employer)
   - After approval, post a job
   - Set wage, location, requirements

4. REGISTER AS WORKER
   - Click "Register as Worker"
   - Add skills and experience

5. APPLY FOR JOB (as Worker)
   - Browse available jobs
   - Apply with message

6. MANAGE APPLICATION (as Employer)
   - Review applications
   - Accept/reject workers

7. COMPLETE JOB (as Employer)
   - Mark job as completed
   - View in employment history

🔧 TROUBLESHOOTING:

Port already in use?
→ Change port in app.py: app.run(port=5001)

Module not found?
→ Activate venv and: pip install -r requirements.txt

Database errors?
→ Delete database: rm -rf database/village_jobs.db
→ Restart: python app.py
